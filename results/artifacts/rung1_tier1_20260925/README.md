# Tier 1 (rung 1): unlabelled adaptation, six encoders — 2026-09-25

**What:** HALO v4 and five released baselines (HARNet-5, HARNet-10, LiMU-BERT-X, UniMTS, NormWear)
under one transductive procedure — EM-Dirichlet (Martin et al., CVPR 2024) with the embedding-affinity
term (μ = 1, 10 neighbours in each encoder's own feature space) — at k = 0, as a function of the
unlabelled pool size N ∈ {0, 50, 100, 500, 2000, all}.

**Protocol:** the 11 sealed single-device 8 s cells. Per cell, queries are split by physical execution
into a fixed scored set (20 %) and a pool (80 %); nested pool draws; metrics on the scored set only.
λ = N. Each encoder's probability features use **its own temperature**, fitted by maximum likelihood
on subject-held-out windows of the 8 training sources (`temperature_calibration_w8.json`; no sealed
data). HALO is scored through its checkpoint's `p_text`; HARNet-5/-10 and LiMU-BERT-X through the
training-bank 1-NN + ConSE bridge; UniMTS and NormWear through their native text heads. Readout
version `ncurve-v2`. Command and git state: `run_provenance.json`.

**Files:** `results.json.gz` (924 rows, one per encoder × cell × N × assignment, plus anchors),
`RESULTS.md` (tables generated by `results/tools/rung1_report.py`), `temperature_calibration_w8.json`,
`run_provenance.json` (+ `run_provenance_first_run.json`); `controls/{mu0,balanced,disjoint}/` (same protocol and temperatures, 924 rows
each, with their own provenance).

## Reading it

- `anchor` is the per-window zero-shot arg-max, i.e. **no unlabelled data at all**. It equals each
  model's published sealed k = 0 number on the same windows (verified for all five baselines and for
  HALO v4 on all 11 cells).
- `N=0` is **not** "no unlabelled data": it transduces over the scored set itself (hundreds to
  thousands of windows per cell). Most of the unlabelled-data effect appears between the anchor and
  N=0; the pool then adds little. Both comparisons are reported.
- Headline (dataset-balanced macro-F1): HALO anchor 47.4 → N=0 50.6 → N=all 51.9 (peak 52.6 at
  N=500). Best baseline UniMTS 31.9 → 35.1 → 34.7. NormWear gains most in relative terms
  (10.4 → 18.4). HARNet-5/-10 and LiMU-BERT-X are flat within ±1.
- Gate A (the pool curve rises for ≥ 1 encoder): passed narrowly (HALO +1.3 and NormWear +2.1 from
  N=0 to N=all).

## Controls (2026-09-26)

Dataset-balanced macro-F1, N=0 → N=all (pool effect):

| LiMU-BERT-X | 23.0 → 22.6 (−0.4) | 23.3 → 20.2 (−3.1) | 23.0 → 22.6 (−0.4) | 33.6 → 27.5 (−6.1) |
| HARNet-10 | 31.6 → 31.4 (−0.3) | 32.8 → 31.8 (−1.0) | 31.6 → 31.4 (−0.3) | 38.5 → 39.5 (+1.0) |
| HARNet-5 | 30.5 → 31.1 (+0.6) | 30.5 → 30.1 (−0.4) | 30.5 → 31.1 (+0.6) | 34.8 → 36.3 (+1.4) |

- **μ = 0:** without the affinity term a larger pool *hurts* HALO; the affinity term is what turns
  HALO's pool into a gain (+2.8 at N=all). It is not uniformly good (UniMTS −1.8 at N=all).
- **Balanced pool:** the curve is not an artefact of the pool's natural class imbalance (N=all is
  the same full pool by construction; intermediate N are smoother).
- **Disjoint classes:** the pool helps even when it holds none of the scored classes. The pool
  effect is therefore not "learning the target classes from unlabelled data"; the likely mechanism
  is explaining away — pool windows of the other classes anchor those classes' clusters, so scored
  windows the text had wrongly pulled there are released. Anchors are higher here because F1 is
  over half the roster.

## Caveats

- `results.json.gz` is the 2026-09-26 re-run with per-label F1 and predicted-class counts per row;
  its macro-F1 is bit-identical to the first run on all 924 rows (determinism check). The first
  run's provenance is kept as `run_provenance_first_run.json`. The control runs predate the extra
  telemetry.
- Scored and pool sets share subjects (split by execution, not subject); disclosed per row.
- The ConSE providers' zero-shot includes a supervised nearest-neighbour bridge on the training bank.
