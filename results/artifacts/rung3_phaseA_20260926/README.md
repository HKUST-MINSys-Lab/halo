# Tier 3 (rung 3) Phase A: full fine-tune and from-scratch specialist — 2026-09-26

**What:** four encoders with a trainable trunk under the encoder contract — HALO v4, HARNet-5,
LiMU-BERT-X, UniMTS — adapted with k ∈ {1, 4, 16} labelled windows per class by (a) **full
fine-tune** (released weights, whole encoder at 0.1× the head's lr) and (b) **from-scratch
specialist** (same architecture, random init). HARNet-10 and NormWear have no trunk under the
contract (n/a by design; NormWear's authors never fine-tune).

**Protocol:** the 11 sealed single-device 8 s cells; rung 1's fixed scored set (20 % of executions);
supports drawn from the execution-disjoint pool with rung 1's seeds (draw 0 = the same windows as
rung 1's and the probe run's draw 0). Fixed a-priori budget: 300 steps, batch 32, AdamW, cosine,
head lr 1e-3, weight decay 0.05. The head is a **cosine classifier** (scale 10) on each model's own
pooled feature — trunk feature scales differ >1000× per dimension and a plain linear head measured
scale rather than representation (journal 2026-09-26 §6; decided before any Phase-A row).

**Files:** `draw0/<model>/results.json.gz` (33 rows per treatment per model: 11 cells × 3 k; per row
macro-F1, accuracy, per-label F1, predicted-class counts, fit seconds, first/final loss, trainable
parameters) and `run_provenance.json`; `RESULTS.md` (generated by `results/tools/rung3_report.py`
together with the frozen-feature run `results/artifacts/rung3_probe_20260925`, which has 3 draws);
`timing_profile.speedscope.json` (py-spy of the one-cell timing run); `draw12/<model>/` (draws 1–2;
HARNet-5 and LiMU-BERT-X so far).

## Reading it (draw 0 only, dataset-balanced macro-F1, k = 1 / 4 / 16)

| encoder | frozen enrollment | linear probe | full fine-tune | from scratch |
|---|---|---|---|---|
| HALO v4 | 53.1 / 66.0 / 71.8 | 52.0 / 66.6 / 72.7 | 50.1 / 69.7 / 76.2 | 42.2 / 59.6 / 73.2 |
| UniMTS | 47.7 / 60.6 / 60.1 | 42.4 / 57.6 / 60.2 | 50.2 / 64.4 / 67.4 | 34.7 / 44.0 / 59.9 |
| HARNet-5 | 34.7 / 42.1 / 48.2 | 33.4 / 40.7 / 48.7 | 42.6 / 54.9 / 68.1 | 36.3 / 47.9 / 63.3 |
| LiMU-BERT-X | 45.1 / 51.6 / 55.3 | 40.3 / 43.2 / 50.5 | 45.1 / 58.3 / 60.8 | 41.6 / 52.2 / 61.7 |

- On draw 0, HALO **frozen** (no parameter update) ≥ every baseline's **full fine-tune** at every k
  (53.1 vs 50.2, 66.0 vs 64.4, 71.8 vs 68.1). **Draws 1–2 weaken this at k = 16:** HARNet-5's full
  fine-tune over 3 draws is 41.1 / 56.0 / 70.7 (draws at k = 16: 68.1, 71.6, 72.2) against HALO
  frozen's 3-draw 53.9 / 67.1 / 71.3 — a near-tie at k = 16. LiMU-BERT-X full fine-tune over 3
  draws: 41.7 / 58.1 / 63.0. HALO and UniMTS draws 1–2 pending.
- Fine-tuning HALO pays from k = 4 (+3.7 over frozen) and k = 16 (+4.4); at k = 1 it is below
  frozen enrollment (50.1 vs 53.1).
- Pretraining is worth most at small k: HALO pretrained − scratch = +7.9 / +10.1 / +3.0; UniMTS
  +15.5 / +20.4 / +7.5. On draw 0 at k = 16 a from-scratch HALO architecture (73.2) is above
  every fine-tuned baseline (HARNet-5's 3-draw mean is 70.7; confirm with HALO's draws 1–2).
- Fine-tuning helps HARNet-5 most (+9 to +19 over its probe).

## Caveats

- **One support draw.** The frozen-feature run shows ≈ 5 points of draw-to-draw spread at k = 1
  for every model; draws 1–2 are running. Treat k = 1 differences under ~5 as unresolved.
- LiMU-BERT-X does not fully fit its supports in the budget (mean final loss 0.50 full, 0.24
  scratch; see the fit-diagnostics table). The cosine head removed the scale problem; this residual
  is the 56k-parameter, 72-dim model. Not re-tuned (no dev split).
- Scored and pool sets share subjects (split by execution, not subject), as in rung 1.
- Budgets fixed a priori and identical for every model; a per-model tuned budget could move numbers.
